# 📊 Sales Forecast Model

## Project Overview
A machine learning model to forecast future sales using historical data.
Built using Python with Polynomial Regression achieving **94.95% accuracy**.

## Business Problem
Businesses struggle to plan inventory, staff, and budget without knowing
future sales. This model predicts next 6 months of sales so managers
can make data-driven decisions.

## Tools Used
- Python, Pandas, NumPy
- Scikit-learn (Polynomial Regression)
- Matplotlib (Visualization)

## Model Performance
| Metric | Value |
|--------|-------|
| Accuracy | 94.95% |
| MAE | ₹4,289 |
| RMSE | ₹4,882 |
| Training Data | 30 months |
| Test Data | 6 months |

## Business Insights
- Sales show consistent upward trend — healthy business growth
- Peak season observed in April–May months
- 6-month forecast total: ₹6,66,434
- Recommended: Increase inventory 2 months before peak season

- **Store Owner**: Plan stock orders based on predicted demand
- **Startup Founder**: Set realistic revenue targets for investors
